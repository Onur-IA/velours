# Velours

Un poker roguelike à construction de paquet, fait maison : noms, règles, pixels, musique et sons sont générés en code.
Aucun asset externe. Jouable dans le navigateur, au doigt sur téléphone, installable sur l'écran d'accueil, et hors ligne.

La sauvegarde reste dans ton navigateur (localStorage). Rien n'est envoyé nulle part.
